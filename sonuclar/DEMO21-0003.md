# DEMO21-0003 – Sonuç

- **İstenen:** $TMP'de, ekrana sadece "VS Code" yazdıran yeni ZOA_DENEME2 programının oluşturulması.
- **Yapılan:**
  - ZOA_DENEME2 sistemde yoktu; $TMP paketinde "Deneme programı 2" açıklamasıyla PROG olarak oluşturuldu (request kullanılmadı).
  - Kaynak `REPORT zoa_deneme2.` iskeletiyle sözdizimi kontrolünden geçti ve aktive edildi.
  - `WRITE 'VS Code'.` satırı eklenemedi: ADT MCP'de program kaynağı yazma aracı yok, PROG için aksiyon da desteklenmiyor ("perform actions in the editor").
- **Sonuç:** Program $TMP'de var ve aktif, ancak sadece `REPORT zoa_deneme2.` içeriyor; WRITE satırı eksik. Emir tamamlanamadı.
- **Sonraki adım:** `WRITE 'VS Code'.` satırı VS Code ADT editöründe elle eklenip aktive edilsin mi, yoksa yürütücüye kaynak yazma yetkisi/aracı (ör. yerel çalışma alanı erişimi) mı verilecek?
