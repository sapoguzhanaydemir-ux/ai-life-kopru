# DEMO21-0001 – Sonuç

- **İstenen:** S4H/100'de $TMP paketinde ZOA_DENEME adlı bir deneme programı oluşturulması.
- **Yapılan:**
  - ZOA_DENEME'nin sistemde olmadığı doğrulandı.
  - PROG ZOA_DENEME, $TMP paketinde "Deneme programı" açıklamasıyla oluşturuldu (request kullanılmadı).
  - Planlanan `WRITE 'Deneme'.` satırı eklenemedi: ADT MCP'de kaynak kod yazma aracı yok.
- **Sonuç:** Program $TMP'de var, kaynakta yalnızca `REPORT zoa_deneme.` satırı bulunuyor. Plan tam uygulanamadı.
- **Sonraki adım:** Program bu haliyle (yalnızca REPORT satırıyla) kabul edilsin mi, yoksa WRITE satırı SE38/ADT üzerinden elle mi eklensin?
