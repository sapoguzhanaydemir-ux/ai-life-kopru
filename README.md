# ai-life-kopru

AI LIFE panelinden verilen iş emirlerinin müşteri makinesindeki Claude Code'a taşındığı köprü reposu.

- Emirler: `emirler/` · Sonuçlar: `sonuclar/` · Tanımlar: `tanimlar/`
- Yürütücü kuralları: `CLAUDE.md`
- Müşteri makinesinde: repoyu klonla, `makine.md`'yi doldur, VS Code'da Claude Code'a **"emirleri işle"** de.
