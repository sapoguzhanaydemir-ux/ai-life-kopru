## Plan
- **Sistem:** S4H / 100 (ADT: S4H_100_XOAYDEMIR_TR)
- **Nesne:** PROG ZOA_DENEME, paket $TMP
- **Değişiklik (deneme 2):**
  1. ZOA_DENEME'nin güncel kaynağı okunacak (bilinen içerik: yalnızca `REPORT zoa_deneme.`).
  2. Kaynağa T001K'yı okuyup WRITE ile listeleyen kod eklenecek: `SELECT * FROM t001k INTO TABLE @DATA(lt_t001k) UP TO 100 ROWS.` + `LOOP ... WRITE: / bwkey, bukrs, ... ENDLOOP.` (ilk 100 kayıt, mevcut satırlar korunur).
  3. Sözdizimi kontrolü yapılıp program aktive edilecek.
  4. Program ADT üzerinden çalıştırılabiliyorsa liste çıktısı sonuca eklenecek; çalıştırılamıyorsa sonuçta "çıktı alınamadı" yazılacak ve kod ekte verilecek.
- **Request:** $TMP yerel paket olduğundan request kullanılmayacak ("Mevcut kullan" tercihi uygulanamaz).
